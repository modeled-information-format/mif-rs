---
title: "No MIF document found under the prune root"
description: "mif-cli prune found no document under its root and refused to remove every vector in the store."
---

**Type URI:** `https://modeled-information-format.github.io/mif-rs/references/errors/mif-cli-prune-empty-root/v1`
**HTTP status:** 400
**Exit code:** 2
**Emitted by:** `mif-cli` (`CliError::PruneEmptyRoot`)

## Message

```
no MIF document found under {root}; refusing to prune every vector in the store
```

## Cause

`mif-cli prune --root DIR` removes every stored document whose id is carried
by no file under `DIR`. No `.md` file with frontmatter and no JSON-LD file
under `DIR` carried an id, so the prune would have emptied the store. This
is almost always a wrong `--root`, so nothing is removed.

## Suggested fix

**MaybeIncorrect** — check `--root` names the directory that holds the
ingested documents.
