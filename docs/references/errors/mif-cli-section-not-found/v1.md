---
title: "No such section is stored for the document"
description: "mif-cli get-passage found the document but nothing stored for it under the heading asked for."
---

**Type URI:** `https://modeled-information-format.github.io/mif-rs/references/errors/mif-cli-section-not-found/v1`
**HTTP status:** 404
**Exit code:** 3
**Emitted by:** `mif-cli` (`CliError::SectionNotFound`)

## Message

```
no section headed '{heading}' is stored for document '{id}'
no section summary is stored for document '{id}'
```

## Cause

`mif-cli get-passage ID --heading HEADING` found the document, but the store
holds no section of it with that heading. The heading is matched exactly, as
`mif-cli search --show-passage` reports it. Sections exist only for headings
of level 1 to 3 that have text of their own, and the `Relationships` and
`Navigation` sections are not stored.

A document ingested by a release before 0.13.0 has no sections and no
summary text until it is ingested again; `mif-cli corpus-stats` counts such
documents as `documents_without_text`.

## Suggested fix

**MaybeIncorrect** — use a heading exactly as `mif-cli search --show-passage`
reports it, or ingest the document again with this release.
