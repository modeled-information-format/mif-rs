---
title: "Some documents were not ingested"
description: "A mif-cli ingest of several files or a directory finished with one or more documents failing."
---

**Type URI:** `https://modeled-information-format.github.io/mif-rs/references/errors/mif-cli-ingest-batch-failed/v1`
**HTTP status:** 422
**Exit code:** 2
**Emitted by:** `mif-cli` (`CliError::IngestBatch`)

## Message

```
{failed} of {total} documents were not ingested
```

## Cause

`mif-cli ingest` was given several files or a directory, attempted every
document, and one or more of them failed: unreadable, not conformant to the
canonical schema, not a lossless round trip, or not embeddable. Each failed
document is named on stderr with its own error before this one. The
documents that succeeded are stored.

An `ingest` of exactly one file never emits this problem: that file's own
error is reported instead.

## Suggested fix

**MaybeIncorrect** — fix each document named on stderr and ingest again.
