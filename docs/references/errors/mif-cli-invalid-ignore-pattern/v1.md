# Diátaxis: Reference
title: "An --ignore pattern is not a valid glob"
description: "mif-cli ingest or prune was given an --ignore pattern that cannot be read as a glob."
---

**Type URI:** `https://modeled-information-format.github.io/mif-rs/references/errors/mif-cli-invalid-ignore-pattern/v1`
**HTTP status:** 400
**Exit code:** 2
**Emitted by:** `mif-cli` (`CliError::InvalidIgnore`)

## Message

```
invalid --ignore pattern '{pattern}': {source}
```

## Cause

`mif-cli ingest --ignore GLOB` and `mif-cli prune --ignore GLOB` read each
pattern as a glob. This one could not be read, most often because of an
unclosed `[` character class. Nothing is ingested or pruned.

## Suggested fix

**MaybeIncorrect** — write the pattern as a glob: `*` and `?` within one
path component, `**` across them, `[abc]` for a character class.
