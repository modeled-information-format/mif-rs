---
title: "No such section is stored for the document"
description: "The get_passage tool found the document but nothing stored for it under the heading asked for."
---

**Type URI:** `https://modeled-information-format.github.io/mif-rs/references/errors/mif-mcp-section-not-found/v1`
**HTTP status:** 404
**Exit code:** 3
**Emitted by:** `mif-mcp` (`McpError::SectionNotFound`)

## Message

```
no section headed '{heading}' is stored for document '{id}'
no section summary is stored for document '{id}'
```

## Cause

The `get_passage` tool found the document, but the store holds no section of
it with that heading. The heading is matched exactly, as `search_documents`
reports it. Sections exist only for headings of level 1 to 3 that have text
of their own, and the `Relationships` and `Navigation` sections are not
stored.

A document ingested by a release before 0.13.0 has no sections and no
summary text until it is ingested again; `corpus_stats` counts such
documents as `documents_without_text`.

## Suggested fix

**MaybeIncorrect** — use a heading exactly as `search_documents` reports it,
or ingest the document again with `ingest_mif_document`.
